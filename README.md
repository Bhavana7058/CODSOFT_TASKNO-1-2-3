# CODSOFT Data Analytics Internship

## About the Internship
This repository contains the tasks completed as part of my **CodSoft Data Analytics Internship**. The internship helped me gain practical experience in data cleaning, exploratory data analysis, and data visualization using Python.

## Tools & Technologies
- **Programming Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
- **IDE:** Visual Studio Code
- **Dataset:** Sales Dataset (Excel/CSV)

## Tasks Completed

### Task 1: Data Cleaning and Preprocessing
- Imported and explored the sales dataset using Pandas.
- Checked for missing values and duplicate records.
- Reviewed and converted data types where required.
- Prepared the cleaned dataset for further analysis.
- Exported the cleaned data into a CSV file.

**Files:** `task1_data_cleaning.py`, `Cleaned_Sales_Dataset.csv`

### Task 2: Exploratory Data Analysis (EDA)
- Performed descriptive statistical analysis.
- Analyzed sales trends and product categories.
- Examined payment methods and order statuses.
- Identified outliers in the sales data using the IQR method.
- Generated a summary report with key findings.

**Files:** `task2_eda.py`, `EDA_Report.txt`

### Task 3: Data Visualization
- Created visualizations to understand sales performance.
- Developed bar charts for category-wise sales.
- Used line charts to analyze monthly sales trends.
- Created pie charts to examine payment methods.
- Used histograms and scatter plots to explore data distributions and relationships.
- Saved the generated charts for presentation.

**Files:** `task3_visualization.py`, `Task3_Charts/`
